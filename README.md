# MAVI Web Design

The public MAVI Web Design website, hosted on GitHub Pages at https://cchrisso.github.io/.

Built with plain HTML, CSS, and JavaScript. No installation or build is required.

## Editing

- `index.html`: content, services, portfolio, contact links and metadata.
- `styles.css`: responsive layouts and brand styling.
- `script.js`: mobile navigation and footer year.
- `assets/mavi-logo.jpeg`: the original supplied logo, presented through a CSS viewport without modifying the file.

The feedback section contains explicitly labeled fictional layout samples. Replace them with approved real testimonials. Add real project case studies to the portfolio section when available.

To preview locally, serve this folder using any static HTTP server. GitHub Pages should publish `main` from `/ (root)`.
